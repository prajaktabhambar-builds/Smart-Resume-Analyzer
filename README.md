# 🤖 Smart AI Resume Analyzer

An AI-powered resume analysis and career assistance platform built with **Python and Streamlit**.

Smart AI Resume Analyzer helps students and job seekers analyze their resumes, identify skill gaps, build professional resumes, explore jobs, and track their career progress through an interactive dashboard.

## 🚀 Features

### 📄 Resume Analyzer

Upload your resume and analyze it using AI-powered techniques.

- Resume text extraction
- ATS compatibility analysis
- Resume scoring
- Skills identification
- Missing skills detection
- Keyword analysis
- Resume improvement suggestions
- Career recommendations

---

### 📝 Resume Builder

Create a professional resume from scratch.

Features include:

- Personal information
- Professional summary
- Education
- Work experience
- Projects
- Technical skills
- Soft skills
- Languages
- Tools and technologies
- Multiple resume templates
- Resume generation
- Downloadable resume

---

### 📊 Dashboard

Track your resume and career information through an interactive dashboard.

- Resume statistics
- Analysis history
- Skills overview
- Resume scores
- Career progress
- Data visualization

---

### 🎯 Job Search

Explore suitable job opportunities based on your skills and interests.

- Job search
- Job recommendations
- Role-based opportunities
- Skill-based matching
